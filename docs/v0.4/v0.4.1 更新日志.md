## 更新目标

- 为论坛增加后台管理系统 Dashborad 与 AI MCP。
- 编辑器转向 Vrind 编辑器
- 做接口限流、统计
- 支持多端登陆
- 优化前端样式

## 主要更新内容

### 1.1 后台管理

后台管理覆盖以下功能：

- **用户管理**：显示用户列表、(解除)禁用用户、用户等级管理。
- **权限管理**：增删改查、分配角色及权限列表。
- **博客管理**：增删改查博客、控制是否公开
- **标签管理**：增删改查标签、编写标签详情。

### 1.2 Agent MCP

增加 `Agent` 角色，拥有博客的增删改查权限。用户可以在工作台的 "授权管理" 下，创建一个 `Token`，并设置期限、给予该令牌所能具有的权限：

- 查看账号博客(包括私有)列表
- 阅读账号博客(包括私有)
- 编辑账号博客
- 查看账号目录列表

用户可以通过 `parabbs-agent` Skill 或让 AI 阅读相关文档，使得 Agent 能够发送携带 `Token` 的请求而非携带 JWT 令牌模拟用户的方式来编辑网站信息。

Agent Token 一经创建无法修改。

### 1.3 访问控制

使用 AOP，接口限流。

修改登陆 Token 缓存逻辑，改为 Hash 结构存储，使用 jti 隔离，支持多端登陆。

### 1.4 前端改进

- 全站字体替换：英文优先 [Agbalumo](https://fonts.google.com/specimen/Agbalumo) 字体，中文优先 [ZCOOL KuaiLe](https://fonts.google.com/specimen/ZCOOL+KuaiLe) 字体。
- 引入 [Vrind 编辑器](https://github.com/Nobeta-Work/vrind) 替换 Vditor。清除 Vditor 已有自定义化，再重新自定义如下条目：
  - 行内代码字体颜色为，背景为线阵
  - 引用块标识线由默认灰色改为蓝色(dark:黄色)
- 由期刊简洁风转向可爱灵动风。
- 博客列表转为纵向排布。
- 个人主页去除点阵，发布旅程条目扁平化，支持向下滚动载入更多。

### 2.2 AI MCP

#### 数据库

- `sys_role` 表增加 `Agent` 角色。
- 增加表 `agent_token`：

| Field | Type | Constranit | Comment |
| :-: | :-: | :-: | :-: |
| token | BIGINT | PRIME KEY | 主键、业务键 |
| user_id | BIGINT | NOT NULL | 所属用户 |
| name | VARCHAR(50) | NOT NULL | 命名 |
| expire | INT | NOT NULL | 有效时长，单位"天"，-1 为永久 |
| create_time | DATETIME | NOT NULL | |
| update_time | DATETIME | NOT NULL | |
| is_deleted | BOOLEAN | NOT NULL | |

其中，`(user_id, name)` 为联合索引。
