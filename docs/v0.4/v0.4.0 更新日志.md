## 更新目标

命名与开发主体变换。 

##  主要更新内容

- **彼岸论坛** *(Faramita BBS)* 命名及其空间转向 **彼记** *(Para BBS)*
- 产品名由 **Faramita** 转向 *Para*
- 开发主体由 **Faramita** 转向 *Nobeta*

**涉及范围：除 `docs/` 下在 `v0.4.0` 前的版本文件文档文件夹外，修改范围包括 `DOCKER.md`, `GIT.md` 以及前端描述文本、后端描述文本、后端开发主体、数据库命名、仓库、README。

以下是转换示例：
- `faramita.online` → `nobeta.cn`
- `online.faramita` → `cn.nobeta`
- `彼岸论坛` → `彼记`
- `faramita_bbs` → `para_bbs`
- `FRMT BBS` → `Para BBS`
- `faramita` → `para`
- `faramita-bbs` → `parabbs`
- `FARAMITA_*` → `PARA_*`
- `Faramita@Nobeta` → `Para@Nobeta`
- `online.faramita.bbs` → `cn.nobeta.bbs`
